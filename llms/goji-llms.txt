# Goji

> Goji is a private-fund digitisation platform, part of the Euroclear group and regulated by the UK Financial Conduct Authority. Founded in 2015 and backed by Anthemis, it provides end-to-end infrastructure for asset managers, fund administrators and distributors to digitise access to private markets: investor onboarding, KYC/KYB and AML, ISA administration, payments, and debt and equity settlement. The Goji Platform API is REST over HTTPS with HMAC-SHA256 request signing and a webhook event stream.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Goji API reference and website; it is not published by Goji.

## APIs

- [Goji Platform API](https://docs.api.goji.investments/): Investors, KYC/KYB, IF ISA administration, investor and manager payments, debt and equity settlement, bond management, and webhooks. Base URL https://api.goji.investments (sandbox https://api-sandbox.goji.investments).

## Docs

- [API Reference](https://docs.api.goji.investments/): The Goji Platform API reference.

- [Authentication](https://docs.api.goji.investments/): HMAC-SHA256 signed requests in production (x-nonce, x-timestamp, Authorization); Basic HTTP API key + password in the sandbox.

## Conventions

- Idempotency: `X-CLIENT-REQUEST-ID` request header de-duplicates retried writes.
- Request tracing: `X-GOJI-REQUEST-ID` response header.
- Versioning: `version` request header. Dates are ISO 8601.
- Events: platform webhooks (INVESTOR_CREATED, INVESTOR_KYC_STATUS_CHANGE, INVESTMENT_FULFILLED, ISA_PROVISIONALLY_OPENED, TRADE_SETTLEMENT, and more).
